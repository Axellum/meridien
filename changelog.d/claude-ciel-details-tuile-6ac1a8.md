### Changed

- **The *Details* page's sky is a 64-column tile instead of a full-screen image, and the page opens about 46 % faster**: like the main screen (PR 27), the page now lets LVGL repeat a 64 × height tile of the dithered sky (`bg_image_tiled`) instead of keeping a 1.2 to 1.8 MB image in PSRAM, and no longer draws its own gradient under it. Same pixels (180 of 180 PC-bench renders of the scene `details` identical at 50, 28 and 25 lines). On `waveshare-7b` on 2026-11-09 (Sky theme forced, temporary timer, 16 openings each, `main` `1069571` measured the same way): opening the page 187.4 → 102.1 ms, building it 51.7 → 7.6 ms, and the open page takes about 1.17 MB less PSRAM. The exact binary of the commit (without the timer) was not flashed, the sky has not been looked at on the panel and the Tab5 has not been measured. Details: [docs/mesures/details-ciel-en-mosaique.md](../docs/mesures/details-ciel-en-mosaique.md). *(Français : le ciel de la page « Détails » est une tuile de 64 colonnes que LVGL répète, comme sur l'accueil ; l'ouverture de la page passe de 187 à 102 ms sur la 7B, mesuré avec le code du commit et un chronomètre temporaire.)*
