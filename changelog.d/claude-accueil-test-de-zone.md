### Changed

- **The main screen repaints about 10 % faster when a page is closed**: the drawing helpers skip every element that does not touch the band LVGL is repainting, instead of creating a draw task for it in all 26 bands. Closing the settings back to the main screen takes 390 ms instead of 429 ms; opening the settings is unchanged (94 ms). The main screen still needs about 385 ms to repaint: this is a first step ([measurements](../docs/mesures/accueil-zone-de-dessin.md)). The picture does not change: 266 PC renders of the main screen, its themes, time zones and alerts, the details page, the sea page and the wheel are pixel-identical before and after (and a deliberately wrong zone test breaks all 36 renders of the main screen, so the comparison does see a clipped element). Tested on: `tab5-st7121`, 2026-11-09, base commit `c3fd97b` plus this change (self-test with no finger, 4 runs each; looks on the panel itself not compared: see the measurements page).
