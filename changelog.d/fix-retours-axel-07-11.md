### Fixed

- **Tapping « Wi-Fi » in the settings no longer restarts the board**: with the settings open only 9.7 kB of internal RAM was left, and the Wi-Fi scan (link to the ESP32-C6, `esp_hosted`) needs internal RAM for its semaphores; it failed on an `assert` and the board rebooted (twice on 2026-11-07). The whole LVGL interface is now allocated in PSRAM (`main/lvgl_memoire.cpp`, `CONFIG_LV_USE_CUSTOM_MALLOC`), and a scan is refused, with a log warning, when internal RAM is too low (16 kB free, 8 kB largest block: first values, the cost of a scan is not measured yet). Tested on: `tab5-st7121`, 2026-11-07, branch `fix/retours-axel-07-11`: serial log only, internal RAM free 211 kB when the time arrives (74 kB at the same point before), 210 kB with the settings open (9.7 kB before); settings navigated and a scan started by hand, no restart, minimum internal RAM since boot unchanged (148,500 B). Drawing speed was not compared with the old allocator; a longer run is still to be watched.
- **No more permanent pairing frame on the screen**: the banner (address, `.local` name, code) was drawn over every screen with no way to close it. The address, the name and the code are in Settings, card « Réglages depuis un téléphone », with the « Nouveau code » button. Tested on: `tab5-st7121`, 2026-11-07, log only (9 LVGL objects on the main screen); not looked at on the panel by me.
- **Time and sky right from the start**: the main screen waited for the first SNTP answer (about 13 s) before showing the time and a day sky; it now uses the system time as soon as it is plausible (resumed from the hardware clock at start-up, or kept across a software reset), and judges day and night in the clock's time zone until the weather is read. Tested on: `tab5-st7121`, 2026-11-07, log: the right time and date 3.4 s after a restart; the sky itself not looked at by me; a start after a power cut (hardware clock read) not replayed.
