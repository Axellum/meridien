### Changed

- **The main screen's sky is a 64-column tile instead of a full-screen image, and coming back to the main screen is about 24 % faster**: the sky is a vertical gradient dithered with an 8-column pattern, so LVGL now repeats a 64 × height tile (`bg_image_tiled`) instead of reading a 1.2 to 1.8 MB image from PSRAM on every repainted band, and no longer draws its own gradient under it. Same pixels (575 of 575 PC-bench renders identical at 50, 28 and 25 lines). Return from the diagnostic screen to the main screen, Sky theme, on `waveshare-7b` on 2026-11-09: 239 ms → 183 ms with this commit's code plus a temporary timer (14 returns each, `main` `1069571` measured the same way), and 1.17 to 1.19 MB more free PSRAM; the exact binary of this commit boots on the board, but the sky itself has not been looked at on the panel and the Tab5 has not been measured. Details and what is not proven: [docs/mesures/accueil-ciel-en-mosaique.md](../docs/mesures/accueil-ciel-en-mosaique.md). *(Français : le ciel est une tuile de 64 colonnes que LVGL répète, au lieu d'une image pleine taille relue de la PSRAM ; le retour à l'accueil passe de 239 à 183 ms sur la 7B, mesuré avec le code du commit et un chronomètre temporaire.)*
