### Added

- **`SECURITY.md`**: how to report a problem, and the security limits written down (Wi-Fi password and settings in the flash without encryption, settings page over plain local HTTP behind a 6-digit code, a binary built with the local Wi-Fi settings contains them, radio coprocessor never updated, third-party services). Read in the configuration files and in `main/reseau.cpp` and `main/serveur_web.cpp` on 2026-11-07; nothing measured on a board.
- **`tools/controle_publication.py`**: looks for what must not become public (MAC addresses, personal paths, the Wi-Fi password by the name of its variable) in the files and, with `--historique`, in the text of every commit of every reference, and lists what a human has to judge (private IP addresses, e-mail addresses, commit identities). `--autotest` checks the check, on a folder and on a two-commit repository it builds. Run on the tree of 2026-11-07 it found four blocking items, now fixed.
- **`docs/publication.md`**: the procedure to make this repository public. Decided by the owner on 2026-11-07: the existing repository itself is flipped, history included (no snapshot). It lists what the history holds, measured on a fresh clone of the remote (270 commits: 4 board MAC addresses, the Windows user name in 7 commits, private IP addresses, the personal e-mail address that is already public; no Wi-Fi password and no secret) and the checklist before the flip. Nothing is published yet.
