### Changed

- **The weather is in the first image**: the weather cache stored in NVS is read before the main screen is created, so the first image already shows the weather instead of "météo indisponible" until the next 500 ms timer tick. Measured cost on the Waveshare 7B: reading the cache takes 5 ms, but the first render now also draws the weather (+195 ms), so **the backlight comes on 191.5 ms later (1029.2 ms → 1220.7 ms, mean of 6 restarts each)**; the complete image appears earlier than before (estimated 0.3 to 0.5 s, not measured). [Measurement](../docs/mesures/demarrage-7b.md#6-lot-p5--la-météo-du-cache-avant-la-première-image-mesuré-le-09112026). *La météo est dans la première image : la lumière s'allume 0,19 s plus tard, l'image complète arrive plus tôt.* Tested on: `waveshare-7b`, 2026-11-09, commit `560186f` (timings read on the log; the image has not been judged by eye yet; Tab5 not tested on board).
