### Changed

- **The main screen's sky is a 64-column tile instead of a full-screen image, and coming back to the main screen is about 24 % faster**: the sky is a vertical gradient dithered with an 8-column pattern, so LVGL now repeats a 64 × height tile (`bg_image_tiled`) instead of reading a 1.2 to 1.8 MB image from PSRAM on every repainted band, and no longer draws its own gradient under it. Same pixels (575 of 575 PC-bench renders identical at 50, 28 and 25 lines), about 1.1 to 1.75 MB of PSRAM freed. Return from the diagnostic screen to the main screen, Sky theme: 235 ms → 178 ms on `waveshare-7b`, measured with equivalent test binaries on 2026-11-09 (base commit `1069571`); the binary of this very commit has not been flashed (not tested on board). Details and what is not proven: [docs/mesures/accueil-ciel-en-mosaique.md](../docs/mesures/accueil-ciel-en-mosaique.md). *(Français : le ciel est une tuile de 64 colonnes que LVGL répète, au lieu d'une image pleine taille relue de la PSRAM ; le retour à l'accueil passe de 235 à 178 ms sur la 7B, mesuré avec des binaires d'essai équivalents.)*
